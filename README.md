# 🎓 Admission Hub (বাংলাদেশ পাবলিক বিশ্ববিদ্যালয় ভর্তি পোর্টাল)

**Admission Hub** হলো বাংলাদেশের সকল পাবলিক বিশ্ববিদ্যালয়ের ভর্তি বিজ্ঞপ্তি (Admission Circular), আবেদনের শেষ তারিখ, ভর্তি পরীক্ষার ক্যালেন্ডার, জিপিএ যোগ্যতা যাচাই এবং স্বয়ংক্রিয় নোটিশ মনিটরিং পোর্টাল।

## ✨ প্রধান ফিচারসমূহ

1. **🤖 স্বয়ংক্রিয় অফিশিয়াল ওয়েবসাইট মনিটরিং (GitHub Actions Monitor):**
   - `data/sources.json`-এ ইউজিসি (UGC) তালিকাভুক্ত **৫৩+ পাবলিক বিশ্ববিদ্যালয় এবং প্রধান ভর্তি পোর্টালসহ মোট ৬২টি অফিশিয়াল ওয়েবসাইট** যুক্ত করা আছে।
   - `.github/workflows/site.yml` প্রতি ৩ ঘণ্টা পরপর স্বয়ংক্রিয়ভাবে `node scripts/monitor.js` রান করে প্রতিটি বিশ্ববিদ্যালয়ের ওয়েবসাইট চেক করে এবং নতুন কোনো ভর্তি বিজ্ঞপ্তি, নোটিশ বা PDF পেলে `data/updates.json` ও `data/status.json` আপডেট করে।
   - নতুন নোটিশ পাওয়া মাত্রই ওয়েবসাইটের নোটিফিকেশন বেল, ব্রাউজার নোটিফিকেশন এবং (ঐচ্ছিক) **Telegram Bot**-এ তাৎক্ষণিক অ্যালার্ট পাঠানো হয়।

2. **📅 ভর্তি ক্যালেন্ডার ও Google Calendar / .ics এক্সপোর্ট:**
   - প্রতিটি সার্কুলারের আবেদন শুরুর তারিখ, আবেদনের শেষ দিন (Deadline) এবং ভর্তি পরীক্ষার দিন বাংলা ক্যালেন্ডারে দেখায়।
   - এক ক্লিকে **Google Calendar**-এ যুক্ত করা অথবা `.ics` ক্যালেন্ডার ফাইল ডাউনলোড করে ফোনে/কম্পিউটারে সেভ করার সুবিধা।
   - যেকোনো শিক্ষার্থী **"➕ নিজের জন্য সার্কুলার যুক্ত করুন"** বাটনে ক্লিক করে নিজের ব্রাউজারে কাস্টম সার্কুলার ও পরীক্ষার তারিখ ক্যালেন্ডারে যোগ করতে পারবে।

3. **🧮 জিপিএ যোগ্যতা যাচাই (GPA Eligibility Checker):**
   - বিভাগ (বিজ্ঞান, মানবিক, ব্যবসায় শিক্ষা) এবং SSC ও HSC জিপিএ দিলে কোন কোন বিশ্ববিদ্যালয়ে আবেদন করা যাবে তা তাৎক্ষণিক দেখায়।

4. **🔍 সার্চ, ক্যাটাগরি ফিল্টার, বুকমার্ক ও ডার্ক/লাইট মোড:**
   - বিশ্ববিদ্যালয়ের নাম বা সংক্ষিপ্ত নাম (DU, BUET, RU, CU, JU, GST, DGME ইত্যাদি) দিয়ে সার্চ ও ক্যাটাগরি ফিল্টার।

## 🚀 কীভাবে GitHub Pages ও অটো-মনিটরিং চালু করবেন

1. **GitHub-এ কোড পুশ করুন:**
   ```powershell
   cd C:\Users\asifr\.gemini\antigravity\scratch\admission-hub
   git push -u origin main
   ```
2. **GitHub Pages চালু করুন:**
   - আপনার রিপোজিটরির **Settings → Pages**-এ যান।
   - **Build and deployment → Source** থেকে **GitHub Actions** সিলেক্ট করুন।
   - সাইটটি লাইভ হবে: `https://naimurbijoy500.github.io/Admission-Hub/`

3. **টেলিগ্রামে তাৎক্ষণিক নোটিফিকেশন পেতে (ঐচ্ছিক):**
   - টেলিগ্রামে `@BotFather` থেকে একটি বট খুলে `TELEGRAM_BOT_TOKEN` নিন এবং আপনার চ্যাট আইডি (`TELEGRAM_CHAT_ID`) নিন।
   - রিপোজিটরির **Settings → Secrets and variables → Actions → New repository secret**-এ গিয়ে `TELEGRAM_BOT_TOKEN` এবং `TELEGRAM_CHAT_ID` যোগ করুন।

4. **লোকালি মনিটর স্ক্রিপ্ট রান করতে চাইলে:**
   ```powershell
   node scripts/monitor.js
   ```
